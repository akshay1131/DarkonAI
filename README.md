# DarkonAI

> AI-Powered Cybersecurity Vulnerability Assessment and Risk Analysis Platform

## Overview

DarkonAI is an AI-powered cybersecurity platform designed to automate vulnerability assessment, threat detection, and security risk analysis. It scans target systems, identifies vulnerabilities, prioritizes risks, and generates AI-assisted security reports through an intuitive dashboard.

## Features

- Automated vulnerability scanning
- CVE analysis
- AI-powered threat assessment
- Risk scoring
- Security dashboard
- PDF report generation
- Email notifications
- Power Grid / SCADA simulation
- MITRE ATT&CK mapping

## Tech Stack

- Frontend: React, Vite, Tailwind CSS
- Backend: Flask, Python
- Database: SQLite
- AI: LLM-powered threat analysis
- Security: Nmap, NVD CVE API

## Installation

### Clone

git clone https://github.com/akshay1131/DarkonAI.git

### Backend

cd backend
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python app.py

### Frontend

cd frontend
npm install
npm run dev
